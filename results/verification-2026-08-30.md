## Failure-path boundary

The private request sidecar's local source was confirmed byte-identical to the
live source and passed 125 checks. Isolated component tests produced these
results:

- Connection refusal or timeout before response headers returned HTTP 502 with
  `{"error":{"message":"error","type":"bad_request"}}`.
- An upstream HTTP error status and body passed through unchanged.
- An upstream failure after SSE began retained HTTP 200 and closed without the
  terminating zero chunk. Clients therefore observe a truncated stream.

Timeout and mid-stream failure were not injected into the standing endpoint.
These three results characterize the byte-identical sidecar component, not the
complete live gateway under fault injection.

No new performance benchmark was run on August 30. The old 52.4% and 54.8%
normalized-wall reductions derive from the August 21 records and used different
GPU memory utilization settings across arms. The standing performance claim now
comes from the separately published September 3 matched comparison.
